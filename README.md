# held-dog-sleep

## Purpose

A small Node 22 program that writes a single, quiet still-life sentence to `entry.txt`. The sentence describes sleep arriving gently and gives the reader a contained moment of rest.

## Run

```sh
node main.ts
```

Set `MAKEFUN_OUTPUT_DIR` to choose a different output directory; otherwise the program writes to `./output`.
